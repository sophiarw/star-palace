# Hybrid sky labels

The blind review replaced always-visible cluster headings with two spatial levels named from folder-derived region/neighborhood labels. Broad groups fade out over zoom .035–.10; smaller clusters fade in over .045–.12 and out over .40–.85. File captions take over nearby.

Groups come from the complete available summary markers, independent of visible tiles, hydration, hover, selection and camera. Stable ID ordering seeds broad 6,000-world-unit groups, each subdivided into 1,600-unit groups. Anchors are actual member positions. A dominant folder name labels a group; mixed groups use the two most represented names. These are geographic descriptions, not semantic confidence claims or authored folder membership. Labels are capped at 24 broad and 96 small groups. Above the summary’s 4,096-marker sampling threshold, labels describe that sample.

A fixed priority and separation threshold delays crowded names until their anchors have enough screen space. Opacity is a continuous function of zoom; no time-based heading animation, hover ordering or viewport collision lottery. Labels clip naturally at edges. Summary membership, renames, explicit filtering or changed positions can rebuild derived groups; label identity across arbitrary indexing edits is not a persistence promise. Saved file positions are never changed.

Click a sky name to frame its spatial members. The Library sidebar still selects actual regions/folders and isolates those files, which may be spread across the atlas. Broad and cluster names fade away entirely before close reading.
