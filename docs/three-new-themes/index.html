Rollout

Whichever
we pick, the path
is the same.

All five themes share the rendering pipeline. The base fixes (DPR-aware sprite cache, halo grading, per-theme smoothing modes) ship first; theme work is independently mergeable on top.

Stage 1 · Foundation
DPR-aware sprite cache + halo grading

Fixes the regression that triggered this work. Every theme inherits the fix. No theme choice required to merge — ship now.

Stage 2 · Theme renderer
Implement chosen theme(s)

Each theme is ~400 lines of canvas drawing code, registered against the existing 10 type slots. Pair-themes (e.g. JWST + Atari for day/night mode) double the work, not the risk.

Stage 3 · Background
Per-theme background layer

Deep-field nebula (JWST), Tron-grid (Vapor), pixel star-field (Atari), starfield+sparkles (Lost), watercolor washes (Bio). Cached gradient texture per resize.

The Ask

Pick a voice.

My recommendation:
JWST default,
plus one wildcard.

JWST is the safe ship — premium, on-brand, what users expect from a "Star Palace." Pair it with one wildcard (my pick: Bioluminescent, as a paid skin) to give the product a distinct identity beyond the genre default. Atari and Lost are great seasonal events.

  • Which themes ship? JWST only; JWST + 1 wildcard; or all five over time?
  • Wildcard pick: Vapor (loud), Atari (playful), Lost (narrative), or Bio (organic)?
  • Skin packaging: all-included, paid skins, or unlockable?
  • Land Stage 1 first? The foundation fix is theme-agnostic — green-light independently.
  • Decide for me · Default = JWST + Bio
