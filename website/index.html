02 / Tutorial

A tutorial

Start with one folder. The rest can wait.

Step 01

Folder indexing

In Finder, select a folder and press Option–Command–C to copy its path. In Star Palace, open Manage sources, paste it into Folder path, and choose Index folder. Start with one small folder. Names and text previews work without Ollama.

Tip: reindex the same source to pick up changes.

03 / Installation

Mac installation

Star Palace is an early project for Mac. Free for personal and internal workplace use. You can run it from source today. A drag-to-Applications download is the next step.

Install Node.js 22 using its macOS installer (.pkg); choose v22 on the download page. Open Terminal from Applications → Utilities, run xcode-select --install, and finish that installation before continuing. Those tools include Git.

Read the source on GitHub ↗
Terminal · Get the app
cd ~
git clone https://github.com/sophiarw/star-palace.git
cd star-palace
npm ci
npm start

Open 127.0.0.1:5173 in your browser. Keep Terminal running; press Control C to stop the app.

Next launch ＋

Open Terminal and run:

cd ~/star-palace
npm start

Your indexed library is saved between launches. Add your first folder using the tutorial above.

Optional: search by meaning ＋

Install and open Ollama for Mac, then download the local embedding model:

ollama pull nomic-embed-text

Index or reindex your folders with Ollama running to add embeddings. Names and text search are available without it. The model runs on your computer.

Just want to explore first? ＋

After npm ci, run npm run seed:atlas, then npm run start:demo. Open 127.0.0.1:5174. This uses a separate demo library with fictional files.

Already using Star Palace? Back up ~/.starpalace before upgrading an existing library. Upgrade & rollback notes ↗
